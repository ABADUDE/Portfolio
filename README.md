## 🌟 Overview

This is an ultra-modern, responsive, high-performance portfolio website built specifically for **Muhammad Abdullah Abid**. It highlights his unique engineering combination: low-level hardware & firmware (STM32, ESP32, AVR, RISC-V, Verilog) and modern software/web engineering (C++, JavaScript ES6+, HTML5/CSS3).

### ✨ Key Features
- **Cyber-Engineering Aesthetic:** Dark slate background with glowing neon cyan/emerald circuit traces, glassmorphism cards, and an interactive particle canvas that responds to your cursor.
- **Dynamic Projects Grid & Filter:** Real-time filtering across *Embedded & Firmware*, *Web Development*, *C++ Systems*, and *Machine Learning*, pulling directly from Abdullah's GitHub repositories and project boards.
- **Interactive Engineer's CLI Console:** A built-in terminal emulator where recruiters can type commands like `help`, `skills`, `projects`, `cv`, `contact`, and `sudo hire`.
- **Live Interactive App Showcase:** Embedded interactive order & billing calculator demo derived from Abdullah's Restaurant System.
- **CV Viewer & Instant Download:** Direct integration with `CV_Abdullah .pdf`.
- **Custom Profile Photo Support:**
  - Includes a stylish vector badge fallback (`assets/avatar.svg`).
  - Supports adding a photo by dropping `profile.jpg` or `profile.png` into `assets/`.
  - Built-in "Change Photo" button to upload and preview images immediately in the browser.
- **Meta Verified Certifications:** Direct verified links to Coursera / Meta credentials.
- **Dual Themes:** Seamless toggle between Cyber Dark mode and Clean Light mode.

## 🚀 How to Run Locally

You can open `index.html` directly in any web browser!

Alternatively, start a local server using Python:

```bash
# In the portfolio directory:
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).

## 📸 How to Add Your Profile Photo

You have two easy ways:

1. **Direct File Method:**
   - Copy your photo into the `assets/` folder.
   - Name it `profile.jpg` (or `profile.png`).
   - Refresh the page and your photo will appear automatically!

2. **In-Browser Upload:**
   - Click the **"Change Photo"** button under the avatar on the website.
   - Select your photo from your computer. It will load immediately and persist in your browser!

## 🌐 How to Deploy to GitHub Pages (Free Hosting)

1. Create a repository on your GitHub named `portfolio` (or `ABADUDE.github.io`).
2. Push all the files in this folder to your repository:
   ```bash
   git init
   git add .
   git commit -m "Launch Abdullah Abid Engineering Portfolio"
   git branch -M main
   git remote add origin https://github.com/ABADUDE/portfolio.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings** → **Pages**.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your portfolio will be live at:  
   **`https://abadude.github.io/portfolio/`** (or `https://abadude.github.io/` if using the username repository)!
